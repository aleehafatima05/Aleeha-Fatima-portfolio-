System Thinking

System thinking means looking beyond individual components and understanding how different parts connect, influence one another and contribute to an overall outcome.

Key ideas

What this area includes

  • Relationships between components
  • Inputs and outputs
  • Workflows
  • Dependencies
  • User needs
  • Evaluating the complete experience
Where I apply it

How I am developing it

Thinking through project structure, user journeys, information flow and how separate features work together.
