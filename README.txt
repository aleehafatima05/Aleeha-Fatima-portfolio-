PUBLISH WITH GITHUB PAGES
1. Upload all files and folders in this ZIP directly into the root of your GitHub repository.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Wait for GitHub Pages to finish publishing.

The homepage file is index.html. Keep the CSS, JavaScript, image assets, and HTML pages together in the repository root so the site works correctly.
