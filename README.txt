ALEEHA FATIMA — COMPLETE PORTFOLIO WEBSITE

This is a complete standalone static website in ONE file: index.html.
It includes HTML, CSS and JavaScript, and does not require a build step.

HOW TO OPEN:
1. Extract this ZIP.
2. Open index.html in Chrome to preview.

HOW TO PUBLISH (static HTML hosting):
1. Back up your existing website first.
2. Upload index.html to your hosting site's published root directory.
3. Replace the previous index.html, publish/deploy if needed, and hard-refresh.

If your site uses React, Vite, or Next.js, do NOT overwrite the project root index.html blindly. Instead integrate the design into your app and run its normal build/deploy process.

The Contact section currently has placeholder links. Edit the profile object near the bottom of index.html to enter your real email, LinkedIn and GitHub URLs.

This is a fictional future-self professional portfolio for an academic assignment. Project descriptions should not be represented as verified achievements outside that context unless accurate.
