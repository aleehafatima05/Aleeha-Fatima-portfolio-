Aleeha Fatima — GitHub Pages Portfolio

FILES
- All HTML pages, CSS, JavaScript and images needed by the website are included.
- Open index.html locally to preview the website. No build tools are required.

PERSONAL PROFILE PHOTO (IMPORTANT)
The hijabi woman using a laptop is an illustrative visual, not a photograph of Aleeha.
To show your own photo in the portfolio, add your chosen portrait to this folder and name it exactly: profile.jpg
The homepage will display it in the small profile-photo tile. You can also replace that tile with a larger portrait later.

BEFORE PUBLISHING
1. In contact.html, replace the placeholder email / LinkedIn details with your real public contact details.
2. In education.html, replace any ADD... placeholders with your confirmed education details.
3. Check every project link and social link before publishing.

UPLOAD TO GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository (or create a new public repository).
3. Upload ALL files and folders from inside this extracted folder to the repository root.
   Important: index.html must be at the top level, not inside another nested folder.
4. Commit the upload.
5. Go to Settings → Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for GitHub Pages to publish, then open the website URL shown on the Pages settings screen.

This is a static HTML/CSS/JavaScript website. The contact form (if shown) is visual unless connected to a form service or backend.
